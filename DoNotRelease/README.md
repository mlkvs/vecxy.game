# НЕ ВЫПУСКАТЬ

Самостоятельный короткий хоррор от первого лица на Vecxy. Одна камера 4 × 5 м, один финал. Всё игровое содержимое на русском, включая 28 голосовых файлов. Прохождение занимает около 6–8 минут. Для игры не нужны интернет, Python, Blender или установленный .NET.

## Запуск

Из корня репозитория:

```bash
./DoNotRelease/run.sh
```

Или запустить готовый исполняемый файл:

```bash
./DoNotRelease/Build/Linux-x64/DoNotRelease
```

Переносимый архив: `Build/NeVypuskat-linux-x64.tar.gz`. Распаковать в любую папку и выполнить `./start.sh`. Системные требования: Linux x86-64, OpenGL 3.3, рабочая звуковая система. Билд содержит собственную среду .NET 10. Не удалять файлы рядом с исполняемым файлом.

WASD — ходьба; мышь — осмотр; E — действие; Escape — пауза; F11 — полный экран. На кровати и стуле можно сидеть; E или WASD возвращают в обычное положение. Ночью E у кровати запускает сон. У раковины последовательные действия включают воду, позволяют попить и закрывают кран. Вода автоматически выключается через 14 секунд.

В настройках доступны общая громкость, эффекты, голос, чувствительность мыши, FOV 75–85°, яркость, субтитры, покачивание камеры и полный экран. Покачивание выключено, субтитры включены по умолчанию. Параметры сохраняются в пользовательском каталоге `DoNotRelease/settings.json` внутри `LocalApplicationData`.

Не обязательно находить каждый объект: у всех сюжетных этапов есть автоматический переход. Игра не требует выхода из камеры или решения головоломок.

## Исходники и сцена

- `Authoring/Cell.blend` — редактируемая сцена Blender.
- `Assets/Scenes/Cell.usda` — сцена Universal Scene Description с геометрией, светом и компонентами; `Assets/Scenes/Compiled/Cell.glb` — её автоматически подготовленный render-кеш.
- `CellScene.cs` — загрузка `Cell.prototype` через `IPrototypes/UsdScene` и создание динамического игрока.
- `PlayerController.cs` — адаптация существующего контроллера Horror: динамическая капсула, ускорение, торможение, без прыжка и бега.
- `Gameplay/GameFlow.cs` — независимая машина состояний с резервными переходами.
- `Gameplay/DialogueQueue.cs`, `Soundscape.cs` — одна очередь реплик, субтитры и управление звуком.
- `RoomController.cs` — управление уже загруженными USD-объектами по ролям; геометрия, свет, коллизии и UI в нём не создаются.
- `CellAuthoring.cs` — компоненты для аддона: взаимодействие, исходное состояние, параметры помещения и дальность света.
- `InteractionSystem.cs` — выбор объектов по лучу и проверка препятствий.
- `RecordingPlayer.cs` — личная запись, соглашение и обратный отсчёт.
- `GameSession.cs`, `GameSettings.cs` — связь систем, меню, пауза и настройки.
- `Assets/Configs/Story.yaml` — этапы, длительности, документы, сюжетные уведомления и срок изоляции. Расстановка, коллизии, подсказки предметов, свет и игровые позы редактируются в Blender.
- `Assets/Configs/Voices.yaml` — тексты, длительности и пути озвучки, порядок личного обращения.
- `Assets/UI/` — русские меню, HUD, документы и экран архива.
- `Assets/Audio/` — вентиляция, электропитание, дыхание, вода, шаги, металл, бытовые звуки, финальный эмбиент и речь.
- `Assets/Shaders/PostProcessing/Retro.glsl` — сохранённый, но отключённый ретро-эффект. Постобработка камеры отключена: изображение выводится без пикселизации, дизеринга, дрожания и виньетки.

## Сборка и проверки

Нужен SDK **10.0.110** из корневого `global.json`.

```bash
./DoNotRelease/build.sh

dotnet run --project DoNotRelease/Tests/DoNotRelease.Tests.csproj \
  -p:VecxySkipAssetPipeline=true -p:VecxySkipNetworkingWeaver=true

python3 DoNotRelease/Tests/validate_assets.py
```

Проверка авторинга (не меняет исходный .blend):

```bash
blender -b DoNotRelease/Authoring/Cell.blend --python DoNotRelease/Tests/validate_authoring.py
```

Для Python-проверки ресурсов требуется PyYAML. Сборку и тестовые компиляции запускайте последовательно: корневые настройки движка используют общий промежуточный каталог `obj/Desktop` для restore-графа.

`build.sh` использует штатный Vecxy CLI, собирает пакеты VPack и самостоятельный Linux-x64 Release-билд. Проект добавлен в `vecxy.game.sln`. Существующий Horror не менялся в рамках создания этой игры.

Авторинг сцены описан в [Authoring/README.md](Authoring/README.md). Сначала сохрани изменения в Blender и нажми **N → Vecxy → Export scene USD**. Сборка проверяет и подготавливает USD-кеш автоматически.

Экспорт сцены и генераторы звука:

```bash
blender -b DoNotRelease/Authoring/Cell.blend --python DoNotRelease/Tools/export_usd.py
python3 -m venv .agents/local/donotrelease/venv
.agents/local/donotrelease/venv/bin/pip install -r DoNotRelease/Tools/requirements.txt
.agents/local/donotrelease/venv/bin/python -m piper.download_voices \
  --data-dir .agents/local/donotrelease/voices ru_RU-denis-medium ru_RU-dmitri-medium
.agents/local/donotrelease/venv/bin/python DoNotRelease/Tools/generate_audio.py
python3 DoNotRelease/Tools/create_content.py
```

Для генерации контента также нужен PyYAML в используемом Python. Готовые ресурсы уже включены; повторная генерация для запуска не требуется. `Cell.blend` — единственный источник размещения объектов. Генератор, пересоздававший локацию из кода, удалён; экспорт не пересоздаёт модель и не сбрасывает ручные изменения.

Отчёт: [Docs/TEST_REPORT.md](Docs/TEST_REPORT.md). Полный список файлов: [Docs/CHANGES.md](Docs/CHANGES.md).

## Ограничения

- Подготовлен и проверен Linux-x64 билд. Windows-сборка в этой поставке не проверялась и не включена.
- Штатный `IAudioManager` не предоставляет позиционирование 3D-источников: используется стереофоническая звуковая среда и отдельные эффекты.
- Финальная запись — аудиомонолог с архивным интерфейсом, без видеоролика и изображения человека.
- Отдельного переключателя разрешения нет: используется штатное окно и полноэкранный режим.
- Голоса синтетические. Применяются модели Piper «Денис» и «Дмитрий»; исходные карточки моделей сохранены в `Assets/Audio/Voice/`.

Во время обычной игры музыка отсутствует. Тихий музыкальный эмбиент появляется только в заключительной части. В Release нет тестового ускорения и отладочного HUD.
