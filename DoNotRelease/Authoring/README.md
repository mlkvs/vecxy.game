# Локация «НЕ ВЫПУСКАТЬ» в Blender

Рабочий источник — **Cell.blend**. Открой файл; **N → Vecxy** показывает компоненты выбранного объекта. Каталог `vecxy.components.json` создаётся сборкой проекта из C#-атрибутов `Authoring`.

В сохранённом Material Preview включены **Scene Lights** и **Scene World**. Не отключай их при оценке света комнаты: иначе Blender подставляет студийный HDRI. Текстуры проходят в USD без дополнительного цветового множителя. **Image Texture → Interpolation → Closest** переносится в игру: пиксели текстур отображаются без линейного сглаживания. Режим Linear также поддерживается; после изменения нужен экспорт и пересборка. Различия моделей освещения Blender и Vecxy всё же могут немного менять блики и общую яркость.

Весь статический состав локации находится в этом файле: геометрия, материалы, свет, коллизии, области взаимодействий, настенные интерфейсы, начальные состояния предметов и игровые маркеры.

## Структура

| Коллекция | Содержимое |
|---|---|
| `01_Окружение` | Пол, стены, потолок, вентиляция, камера, трубы |
| `02_Мебель` | Кровать, стул, стол, раковина, туалет |
| `03_Дверь` | Дверь, люк, полка раздачи, поднос и документ |
| `04_Свет` | Обычные источники Blender, рассеиватель светильника |
| `05_Экраны` | Области архива и индикатора с UI Canvas |
| `06_Маркеры` | Появление игрока, меню и игровые позы |
| `07_Параметры` | Компонент параметров помещения |

Кровать, стул, стол и другие составные предметы имеют корневые Empty. Перемещай корень, чтобы геометрия, коллайдер и дочерние маркеры перемещались вместе. Имена объектов можно менять: игра связывает объекты через компоненты и `Gameplay role`.

## Компоненты

- **Камера / Взаимодействие** — действие по E, русская подсказка и запас области. Область берётся из геометрии всей иерархии предмета; отдельных мировых координат в YAML нет.
- **Physics / Box Collider** — на полу, четырёх стенах, потолке и корнях мебели/двери/полки. Размер и центр локальные. После изменения формы нажми **Fit to model**; перенос и поворот объекта переносят коллайдер автоматически.
- **UI / UI Canvas** — на `ArchiveSurface` и `IndicatorSurface`. Document выбирается из ассетов, режим WorldSpace, Interactive выключен. Размер и положение плейна задают расположение UI в игре.
- **Камера / Исходная видимость** — поднос, документ и струя воды. Они доступны для редактирования в Blender, а при запуске получают заданное начальное состояние.
- **Камера / Параметры помещения** — доля света ночью, фоновое освещение, скорость люка и отключение воды.
- **Камера / Дальность источника** — дальность игрового света. Положение, цвет и мощность задаются обычным источником света Blender и экспортируются в UsdLux. Экспортёр Blender переводит мощность в интенсивность USD.

## Маркеры и роли

| Gameplay role | Назначение |
|---|---|
| `spawn` | Ноги игрока; стандартная локальная +Y аддона — направление вперёд |
| `menu-view` | Камера главного меню |
| `bed-view` | Вид лёжа при пробуждении и сне; дочерний объект кровати |
| `bed-seat` | Положение и начальный взгляд сидя на кровати |
| `chair-seat` | Положение и взгляд сидя на стуле |
| `meal-on-table` | Куда поставить поднос; дочерний объект стола |
| `hatch-open` | Конечное положение люка; дочерний объект двери |
| `hatch`, `meal`, `document`, `water` | Объекты, которыми управляет сюжет |
| `main-light`, `screen-light` | Два источника света |
| `archive-ui`, `indicator-ui` | Настенные интерфейсы |
| `light-diffuser`, `room-settings` | Рассеиватель и параметры помещения |

Кроме `spawn`, маркеры вида ориентируются как обычная камера Blender: взгляд по локальной **−Z**, верх по **+Y**. Маркеры размещены внутри иерархий соответствующих предметов.

## Экспорт и запуск

1. Измени сцену в Blender.
2. Сохрани `Cell.blend`.
3. **N → Vecxy → Export scene USD**.
4. Пересобери игру или запусти Debug-проект; перезапусти сцену.

```text
Authoring/Cell.blend
  → аддон Vecxy
Assets/Scenes/Cell.usda + Textures/
  → штатный cook_usd.py
Assets/Scenes/Cell.usda.usdscene + Compiled/Cell.glb
  → IPrototypes / UsdScene
Assets/Prototypes/Cell.prototype
  → CellScene
```

`Compiled/Cell.glb` — производный render-кеш USD, а не самостоятельный источник локации. Не редактируй кеш вручную. В `CellScene` остаются загрузка USD, динамический контроллер игрока и сюжетные системы; мебель, свет, коллизии и UI из кода не создаются.

Экспорт без окна:

```bash
blender -b DoNotRelease/Authoring/Cell.blend --python DoNotRelease/Tools/export_usd.py
./DoNotRelease/build.sh
```

Для экспорта нужен установленный аддон Vecxy USD Tools. Для подготовки кеша нужен OpenUSD Python; окружение `.agents/local/usd-env` определяется автоматически, как в Horror. В готовом билде Python и Blender не нужны.

После изменения компонентов C# выполни обычную сборку игры: каталог обновится автоматически. При необходимости нажми **Reload project components** в аддоне. Фильтры постобработки остаются выключены.
