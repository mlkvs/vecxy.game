# Отчёт о проверке

Дата: 15 ноября 2026. SDK: 10.0.110. Среда: Linux x86-64, OpenGL, FMOD.

## Автоматические проверки логики

`Tests/DoNotRelease.Tests.csproj`: 65 утверждений.

- Полное прохождение без единого взаимодействия: около 462 секунд.
- Активное прохождение с 50 вызовами взаимодействий на каждом шаге: около 355 секунд.
- Правильный порядок всех состояний, по одному первому и последнему обращению персонала, два суточных цикла.
- Пауза и сброс из каждого сюжетного состояния, включая титры.
- Спам двери не дублирует сюжетные реплики; сон не переносит ранее назначенный переход.
- Реплики воспроизводятся последовательно, между ними выдерживается пауза; очистка очереди освобождает звуковой канал.
- Переход ожидает завершения голоса.
- Проверка луча взаимодействия и параллельного луча, ограничений настроек, финального срока и последней реплики записи.
- Регрессия загрузки VPack: одинаковые пути конфигураций игры и движка больше не вызывают исключение; выбирается конфигурация игры.
- Обратный отсчёт продолжает идти при переходе к финальной реплике и не сбрасывает секунды.

## Проверки ресурсов

Проверены 17 уникальных USD-ролей, 11 компонентов взаимодействия, 13 коллайдеров, два настенных UiCanvas, два UsdLux-источника, начальная видимость предметов и настройки комнаты. В Story.yaml больше нет дублирующих координат взаимодействий и коллизий. Производный GLB-кеш содержит 355 узлов и 6128 треугольников.

## Авторинг Blender → USD

`Tests/validate_authoring.py` выполнен настоящим Blender и штатным экспортёром Vecxy, затем штатным OpenUSD-cooker движка. Тест сдвигает кровать в памяти на 0,27 × 0,11 м, экспортирует временную сцену и проверяет:

- Перенос геометрии, сохранение компонентов и локальной формы коллайдера.
- Перенос дочерних маркеров сидения и положения лёжа.
- Отсутствие изменений положения стула.
- Неизменность исходного Cell.blend по SHA-256.

Исходный Blender-файл сохранён с коллекциями и настроенным видом внутри комнаты. Аддон Vecxy установлен и включён. Геометрия, статические тела, свет и настенные UI загружаются через `Prototypes/Cell.prototype` → `Scenes/Cell.usda`; прямой Models/Cell.glb удалён. Фильтры постобработки выключены.

## Проверка запущенной игры

После перехода на USD проверены главное меню и полное пассивное прохождение в Debug на изолированном X11-дисплее: все состояния завершились возвратом в меню на 464,5 секунде игрового времени. Отдельно запущен новый Release с ресурсами из собственного VPack: настоящим вводом проверены старт из меню, ходьба до стены, отход назад, подсказка взаимодействия и меню паузы. Предыдущие проверки игровых интерфейсов: Отдельный процесс из упакованной сборки проверен на изолированном X11-дисплее:

- Открытие настроек из паузы, возврат, перезапуск через настоящие кнопки интерфейса.
- Во время паузы сюжет не продвинулся; интерфейсы на русском отобразились корректно.
- После перезапуска не выполнялось взаимодействий: игра дошла до всех этапов, личного обращения, обратного отсчёта, финальной реплики, титров и главного меню.
- Зафиксированы изображения двенадцати сюжетных состояний; в журнале нет ошибок импорта и необработанных исключений.
- Этот прогон использовал ускорение только в тестовой Debug-сборке. Производственный Release не содержит соответствующего кода.
- Переносимый Release запускался с собственными VPack и .NET, без чтения ресурсов из проекта. Журнал указывает каталог `Build/Linux-x64/Assets`, а не исходный `Assets`.

## Исправления, обнаруженные проверкой

- В поставку явно добавлен `Assets.manifest`, необходимый штатному загрузчику пакетов.
- В `Vecxy.Platforms/PlatformContext.cs` устранено падение при повторяющихся путях игры и движка. Применено то же правило первого совпадения, которое уже использует `AssetsModule.LoadManifest`.
- Для знака уменьшения в настройках выбран обычный дефис, поддерживаемый комплектным шрифтом.
- Пауза доступна и во время титров. Финальное значение оставшегося срока дополнительно показывается кратким уведомлением для игрока, который стоит далеко от экрана.

Проверка не является длительным нагрузочным тестированием на разных видеокартах. Windows и другие архитектуры не проверялись. Графика и голоса являются процедурными/синтетическими ресурсами.

## Общая сборка репозитория

Проверка `dotnet build vecxy.game.sln` выполнена и остановилась на существующем проекте `Vecxy.Platforms.Android`: в SDK 10.0.110 этой среды не установлен workload `android` (NETSDK1147). Полная сборка solution поэтому не подтверждена. Отдельная Linux-сборка новой игры и её тесты от Android не зависят и прошли успешно. Workload и конфигурации других игр не изменялись.

## Среда Blender

Установленный Blender 5.2.1 сообщает о несовпадении версий системного OpenColorIO и собственного config.ocio и использует запасной цветовой режим. Это предупреждение существующей установки Blender: открытие файла, сохранение, работа аддона, экспорт USD и проверки прошли. Настройки системного OCIO не изменялись.

## Исправление материалов USD

Обнаружено и исправлено лишнее умножение цвета текстуры на `diffuseColor` по умолчанию (0,5). Подключённая текстура USD заменяет значение входа, а glTF умножает её на baseColorFactor; поэтому для подключённого цвета теперь используется белый множитель. Цвета пикселей не переписываются.

В `Vecxy.Usd/Tools/test_cook_usd.py` добавлена регрессия для текстуры без fallback и с явно заданным цветным fallback. До исправления оба случая падали; после исправления весь набор из 13 тестов прошёл. Проверяются также пиксели встроенного PNG. Проверка игровых ресурсов дополнена проверками всех десяти текстурированных материалов.

В сохранённых видах Blender включены Scene Lights и Scene World вместо студийного HDRI. Световые модели Vecxy и Blender различаются, поэтому это не обещание побитового совпадения освещения.

## Фильтрация текстур Closest

Исправлена передача интерполяции изображения Blender через USD в GLB и далее в runtime-материал. Аддон сохраняет режим узла Image Texture в `vecxy:interpolation`, cooker создаёт NEAREST min/mag для Closest. Импортёр GLB теперь читает sampler каждой текстуры; рендерер использует его вместо безусловного Linear. Ближайшая выборка не смешивает соседние пиксели и mip-уровни. Для Linear сохранено прежнее поведение.

Проверки: 13 Python-тестов USD (включая Linear/Closest), 175 проверок игровых ресурсов, 65 проверок C# с настоящим импортом десяти текстурированных материалов игры. Это настройка выборки текстур, постобработка камеры остаётся выключенной.

Повторная общая сборка solution после изменения samplers не прошла: отсутствует Android workload (NETSDK1147); также существующий Sponza ссылается на удалённые API IComponentInstantiator/InstantiateContext/IPrototype. Эти проекты и их исходники в рамках исправления текстур не менялись. Проверяется отдельная Linux-сборка DoNotRelease.
