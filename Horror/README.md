# Horror — Delicate Wash

Основа хоррора от первого лица для ПК. Стартовая локация — ночная прачечная
по предоставленной обложке: дождливые витрины слева, красная вывеска 24/7,
12 стиральных машин вдоль дальней и правой стен, стулья, проволочная тележка,
стойка с телефоном, монитором и журналом. Холодные лампы, красный свет вывески,
потёртые поверхности и ретро-постобработка задают атмосферу.

Запуск из корня репозитория с .NET SDK **10.0.110**:

```bash
dotnet run --project Horror/Horror.csproj -p:VecxyPlatform=Desktop
```

В текущем рабочем окружении SDK также установлен локально:

```bash
PATH="$PWD/.agents/local/dotnet:$PATH" dotnet run --project Horror/Horror.csproj
```

Игрок появляется за стойкой. Обойти её можно справа и выйти в проход между
машинами и тележкой. Пол, стены, витрины и крупная мебель имеют коллизии.
Входная дверь пока закрыта; взаимодействие с телефоном и машинами ещё не реализовано.

| Управление | Действие |
| --- | --- |
| WASD | Ходьба |
| Мышь | Осмотр |
| Левый Shift | Бег |
| Пробел | Прыжок |
| Esc | Освободить курсор и отключить управление ходьбой |
| Кнопка мыши | Снова захватить курсор |
| F11 | Полноэкранный режим |

Одна единица мира — один метр. Комната имеет размер 12 × 10 м и высоту 3,1 м.
Камера расположена на высоте **1,6 м**, скорость ходьбы — **2,5 м/с**, как в
стандартных настройках [Blender Walk Navigation](https://docs.blender.org/api/3.6/bpy.types.WalkNavigation.html).
Для физических столкновений используется капсула высотой 1,8 м и радиусом 0,35 м.
Бег — 4,5 м/с, прыжок — примерно 0,4 м. Диагональное движение нормализовано.
При падении за пределы карты игрок возвращается в точку появления.

`MainScene.cs` загружает локацию, создаёт свет, коллизии и игрока.
`Player.cs` содержит управление и физическое движение.
`Assets/Controls.input` задаёт клавиши.
`Assets/Configs/Laundromat.yaml` содержит точку появления и коллизии;
`LaundromatConfig.cs` проверяет их перед загрузкой.

Геометрия, встроенные текстуры и надписи находятся в `Assets/Models/Laundromat.glb`.
Их исходник — `Tools/generate_laundromat.py`. Для пересоздания нужны Python 3
и Pillow; генератор одновременно обновляет GLB и конфигурацию коллизий:

```bash
python3 Horror/Tools/generate_laundromat.py
```

Все детали модели созданы процедурно, без сторонних моделей или текстур.
Обложка служит визуальным референсом и не встроена в ассеты.
Прежняя модель `Assets/Models/room.glb` сохранена, но в новой сцене не используется.
