# Horror — чистая стартовая сцена

Плоский пол 16 × 16 м, две связанные копии новой стиральной машины и объёмный дождь
с брызгами и звуком. Управление от первого лица. Постобработка выключена.

```bash
PATH="$PWD/.agents/local/dotnet:$PATH" dotnet run --project Horror/Horror.csproj
```

Нужен .NET SDK **10.0.110**. WASD — ходьба, мышь — взгляд, Shift — бег,
пробел — прыжок, Esc — освободить курсор, кнопка мыши — захватить его, F11 — полный экран.
Рост персонажа 1,8 м, камера 1,6 м, скорость ходьбы 2,5 м/с. При падении с края
пола игрок возвращается к точке появления.

Редактируй **[Authoring/Sandbox.blend](Authoring/Sandbox.blend)**.
[Памятка по иерархии, компонентам, прототипам и экспорту](Authoring/README.md).
В самом `.blend` есть текст START HERE и панель **N → Vecxy**.

- `01_Environment`: пол с обычным компонентом Box Collider.
- `02_Instances`: Washer_01 и Washer_02, ссылающиеся на одну модель.
- `03_Lighting`: свет; `04_Markers`: точка появления игрока.
- `90_PrototypeLibrary`: одна общая модель Washer_Prototype с именованными деталями.

`MainScene.cs` создаёт USD-сцену через `IPrototypes`, игрока и независимый дождь.
Вся расстановка, модели, физические формы и свет редактируются в Blender.
`LaundryMachine.cs` показывает, как объявить компонент с полями для аддона.
`RainWeather.cs`, `Shaders/Rain.glsl` и `Models/Weather.glb` отвечают за дождь.
Предыдущая прачечная, улица, дверь и их ассеты удалены.
